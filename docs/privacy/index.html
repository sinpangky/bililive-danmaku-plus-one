中文

本扩展仅在 B 站直播页面提供弹幕 +1、回复、全屏发送、本地收藏和用户主动配置的独轮车循环发送，不收集、出售或共享用户数据，也不使用分析、广告、跟踪或远程代码。

本地数据

设置由 storage.sync 保存。收藏和独轮车配置保存在 storage.local；收藏只在用户明确选择并授权目录后同步到本地 JSON 文件。扩展不会上传收藏。

页面访问与发送

扩展仅访问 live.bilibili.com。普通模式使用 B 站官方输入框；全屏模式可在 B 站页面上下文中发起用户明确要求的官方弹幕请求。CSRF 值只用于当次 B 站请求，不写入存储或诊断，也不发送给 B 站之外的服务。

诊断

诊断仅在用户点击后复制，且不包含弹幕正文、账号信息、Cookie、CSRF、收藏内容、房间号或完整 URL，不会自动上传。

English

This extension provides +1, reply preparation, fullscreen sending, local favorites, and a user-configured repeating sender only on Bilibili Live. It does not collect, sell, or share user data and uses no analytics, advertising, tracking, or remote code.

Local data

Preferences use storage.sync. Favorites and repeating-sender settings stay in storage.local; favorites are synchronized to local JSON files only after the user explicitly selects and authorizes a folder. Favorites are never uploaded by the extension.

Site access and sending

The extension accesses only live.bilibili.com. It uses the official editor in normal mode and may perform a user-requested official danmaku request in the Bilibili page context during fullscreen. CSRF values are used only for that Bilibili request and are never stored, included in diagnostics, or sent elsewhere.

Diagnostics

Diagnostics are copied only after a user action. They exclude danmaku text, account information, cookies, CSRF values, favorites, room identifiers, and full URLs, and are never uploaded automatically.
