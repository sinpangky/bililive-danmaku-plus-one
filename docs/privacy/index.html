中文

Danmaku Echo 不收集、传输、出售或与第三方共享个人数据，也不使用远程代码或分析服务。

本地数据

扩展设置由浏览器的 storage.sync 保存，是否跨设备同步由浏览器账户和浏览器设置决定。弹幕收藏及其必要的显示资源信息仅保存在 storage.local，不会由本扩展上传。卸载扩展或清除扩展数据可能删除这些内容。

页面访问与权限

扩展仅在虎牙直播、哔哩哔哩直播、抖音直播和斗鱼直播页面识别弹幕，并通过网站现有的官方输入框和交互控件执行用户明确发起的 +1 或回复操作。scripting 权限仅用于抖音直播单页路由切换后恢复扩展运行时。扩展不会读取或保存 Cookie、密码、CSRF、登录令牌或请求体。

诊断信息

“复制当前页面诊断”只在内存中生成结构化状态，并在用户点击后复制到剪贴板。诊断不包含弹幕正文、用户名、UID、房间号、完整 URL、Cookie、CSRF、收藏内容或请求体；扩展不会自动上传或持久化诊断。

变更与联系

政策变更会在此页面和项目版本记录中公布。问题可通过 GitHub Issues 联系维护者。

English

Danmaku Echo does not collect, transmit, sell, or share personal data. It does not use remote code or analytics services.

Local data

Extension preferences are stored with the browser's storage.sync; browser account settings determine whether they synchronize between devices. Danmaku favorites and the resource metadata needed to display them stay in storage.local and are never uploaded by this extension. Uninstalling the extension or clearing extension data may remove them.

Site access and permissions

The extension recognizes danmaku only on Huya Live, Bilibili Live, Douyin Live, and Douyu Live pages. It uses the sites' existing official editors and controls for user-initiated +1 and reply actions. The scripting permission is used only to restore the extension runtime after Douyin single-page navigation. The extension does not read or store cookies, passwords, CSRF values, login tokens, or request bodies.

Diagnostics

“Copy current-page diagnostics” generates structural state in memory and copies it only after a user click. It excludes danmaku text, usernames, UIDs, room identifiers, full URLs, cookies, CSRF values, favorites, and request bodies. Diagnostics are neither uploaded nor persisted automatically.

Changes and contact

Policy changes will be published on this page and in the project changelog. Contact the maintainer through GitHub Issues.
