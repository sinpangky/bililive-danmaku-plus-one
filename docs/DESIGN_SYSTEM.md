# bililive-danmaku-plus-one 设计规范

## 设计命题

bililive-danmaku-plus-one 是直播画面里的快捷工具，不是独立内容平台。界面应当低打扰、直接、紧凑，并与 `+1` 操作形成同一套视觉语言。

标志性元素是灰黑主表面上的白色强调轨：一条连续白线或沿同一轴线排列的白色标记，用来表达弹幕在不同直播间之间被收藏和再次发送。它只用于当前范围、当前选择和主要动作，不作为装饰铺满页面。

## 色彩

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 深灰黑 | `#17191D` | 收藏面板主表面 |
| 次级灰黑 | `#24272C` | 输入框和计数器 |
| 强调白 | `#FFFFFF` | 主要动作、当前选择和正文 |
| 浅灰 | `#C7CBD1` | 次要说明和元数据 |
| 暗线 | `rgb(255 255 255 / 16%)` | 分隔线与控件边界 |
| 成功色 | `#27AE60` | 成功反馈弹窗 |
| 失败色 | `#FF4747` | 失败反馈弹窗和错误状态 |
| 警告色 | `#E6A000` | 危险或需要注意的反馈弹窗 |

收藏面板不继承直播操作条的自定义色，保持灰黑主体和白色强调，确保在不同直播画面上都有稳定对比度。

## 字体

- 标题与正文：`"Segoe UI", "Microsoft YaHei UI", "PingFang SC", sans-serif`
- 数字、快捷键与 `+1`：`Bahnschrift, "Segoe UI", sans-serif`
- 标题使用 500–600 字重；避免超大粗体和营销式英文眉题。

## 结构

### 直播间收藏面板

```text
┏ 白色强调轨  +1  功能面板                             ×
┃ 当前直播间 / 房间名                               3 条
┃ 本房收藏 3     其他直播间 8      全部 11      + 搜索
┃ 其他直播间 / 先选择直播间                 排序：发送次数
┃────────────────────────────────────────────────────
  A 直播间 / 3 条收藏 / 已发送 14 次                ›
┃────────────────────────────────────────────────────
  B 直播间 / 2 条收藏 / 已发送 7 次                 ›
┃────────────────────────────────────────────────────
┃ Alt+Q 打开/关闭  1-9 快速发送  Esc 关闭
```

选择直播间后替换为独立弹幕页：

```text
┃ ‹  A 直播间 / 8 条收藏              排序：发送次数
┃──────────────────────────────────────────────
┃ 1  弹幕内容 / 收藏时间与发送次数     加入本房  发送
┃ 2  弹幕内容 / 收藏时间与发送次数     加入本房  发送
```

- 面板只有一个主表面。
- 列表使用分隔线形成连续阅读流，不为每条内容添加卡片。
- 当前直播间通过白色强调、文字和数字共同表达，不能只依赖颜色。
- 本房收藏直接展示弹幕；“其他直播间”和“全部”先展示直播间，点击后进入独立弹幕页，不允许多个直播间行内展开。
- 默认使用自定义顺序；首次使用时按添加时间正序，用户可通过拖动手柄调整每条弹幕顺序。也可切换发送次数、时间倒序或时间正序，排序只改变弹幕顺序，不打乱直播间层级。
- `发送` 使用与 `+1` 一致的 16px 胶囊；次要操作保持文字化。

### 独轮车

- 与收藏共用同一固定高度的功能面板，切换时顶部位置不移动。
- 内容框初始为两行；配置区支持总次数/总时长、固定/随机间隔和最大长度。
- “当前内容加入收藏”和“添加到独轮车”使用同一房间上下文，发送任务由用户明确点击开始。

### 弹幕操作条

- 操作条水平居中放在所选弹幕正下方，底部空间不足时回退到上方。
- 当前页面首次选择的弹幕作为 `1:1` 基准，后续按实际渲染字号等比例缩放完整操作条。

### 插件收藏说明页

- 使用一张连续白色说明面，不叠加 Hero 卡、功能卡和步骤卡。
- 左侧解释收藏价值，右侧直接展示收藏列表结构。
- 下方步骤仅在真实顺序中使用 1–2 编号：收藏 → 打开功能面板。

## 动效

- 面板进入 160–200ms，只使用透明度和位移。
- 悬停与按压 140ms，与现有 `+1` 操作一致。
- 不使用装饰性漂浮、光斑、循环动画或大面积玻璃模糊。
- 始终支持 `prefers-reduced-motion`。

## 禁止模式

- 引入与黑白主题竞争的大面积高饱和主色。
- 每一条信息都放进圆角阴影卡片。
- 英文眉题、无意义的大数字和装饰性渐变。
- 图标外再套独立彩色方块，形成组件库模板感。
- 仅靠颜色区分当前房间、其他房间或危险操作。
