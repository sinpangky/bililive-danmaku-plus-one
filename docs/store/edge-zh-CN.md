# Microsoft Edge 商店资料（2.2.0）

## 单一用途描述

Danmaku Echo 为虎牙、哔哩哔哩、抖音和斗鱼直播提供统一的弹幕快捷操作：识别侧边聊天与视频弹幕，让用户通过网站官方输入框完成 +1、准备回复，并把常用弹幕保存在浏览器本地以便再次发送。

## 许可理由

### 存储理由

`storage` 用于保存用户明确选择的扩展开关、平台样式和操作偏好，并在 `storage.local` 中保存用户主动收藏的弹幕。设置可由浏览器使用 `storage.sync` 同步；收藏不上传、不跨设备同步。升级继续使用 schema v2，不覆盖或清空旧收藏。

### 脚本的合理性

`scripting` 仅用于抖音单页应用从普通页面无刷新进入直播路由时，按已有设置补充启动扩展包内的直播脚本。脚本只在受支持直播路由激活，不下载或执行远程代码，也不读取普通抖音页面内容。

### 主机权限的理由

虎牙、哔哩哔哩、抖音和斗鱼匹配范围用于在直播页面识别侧边聊天及视频弹幕、显示用户启用的快捷操作，并驱动页面已有的官方输入框与按钮。`www.douyin.com/*` 用于检测 SPA 路由进入 `/follow/live/*`；非直播路由只运行轻量 URL 启动器。扩展不访问其他网站。

## 你用的是远程代码吗？

否。

### 正当性

所有 JavaScript、CSS、图片与依赖都包含在提交的 Manifest V3 扩展包中。扩展没有外部 `<script>`、远程 ES 模块、远程 Wasm、`eval()`、`new Function()` 或动态下载并执行代码的行为。

## 数据使用

不收集用户数据。扩展不会收集、上传、出售或与第三方共享个人身份、身份验证、网站内容、浏览历史、位置、健康、财务、通信或用户活动数据。设置由浏览器存储；收藏仅保存在 `storage.local`。用户主动复制的脱敏诊断只在内存生成并进入剪贴板，不会自动上传。
